
# 👋 ¡Hola! Soy Guido Dealbera

### Full Stack Developer | React · Next.js · TypeScript · Node.js

Soy desarrollador de software de Argentina 🇦🇷. Me gusta construir soluciones que resuelvan problemas reales, entender las necesidades detrás de cada producto y participar en todo el proceso de desarrollo.

Tengo experiencia trabajando principalmente en el ecosistema de **JavaScript y TypeScript**, con foco en frontend utilizando React y Next.js, y experiencia desarrollando servicios backend con Node.js, NestJS y Python.

Disfruto involucrarme en los desafíos técnicos, explorar alternativas y tomar decisiones que permitan construir aplicaciones mantenibles, escalables y con una buena experiencia de usuario.

Actualmente también incorporo herramientas de inteligencia artificial en mi flujo de trabajo para mejorar la productividad, explorar soluciones y optimizar el proceso de desarrollo.

Plataforma para la gestión de planes de ahorro inmobiliarios. Desarrollo de funcionalidades para usuarios y administración, incluyendo cuentas corrientes, adelanto de cuotas mediante integración con APIs de pago, comprobantes y herramientas de gestión.

**Durrieu Consignatarios**

Desarrollo de una solución digital para el sector agropecuario, incluyendo bots de WhatsApp y Telegram para gestionar negocios, ofertas y pedidos, junto con una plataforma web de gestión.
